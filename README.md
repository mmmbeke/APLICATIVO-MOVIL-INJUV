# APLICATIVO-MOVIL-INJUV
Desarrollo de la aplicación móvil para el Instituto Nacional de la Juventud, enfocado a los Voluntarios y los tutores de los Voluntariados con el objetivo de atraer más jóvenes por el desplazamiento del uso de las herramientas tecnológicas de plataformas web a aplicaciones móviles más amigables al entorno móvil.

## Backend (API REST)

La API para la app móvil está en [`injuv-backend/`](injuv-backend/README.md) (FastAPI + SQLAlchemy sobre la base Neon compartida con la plataforma web). Despliegue en Render vía [`render.yaml`](render.yaml).
